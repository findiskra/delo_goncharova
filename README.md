# Дело Кирилла Гончарова // Спецпроект издания «Искра»

> **Анатомия системного спойлера: 24,2 млн рублей от мэрии, афера с батарейками, слив выборов в Госдуму и мародерство в «Яблоке»**

Интерактивное антикоррупционное и судебно-форензик расследование деятельности заместителя председателя партии «Яблоко» Кирилла Гончарова.

---

## 🌐 Как открыть и опубликовать

### Локальный просмотр:
Просто откройте файл `index.html` в любом современном веб-браузере (Chrome, Edge, Firefox, Safari).

### Публикация на GitHub Pages (в 3 клика):
1. Создайте новый репозиторий на GitHub (например, `delo-goncharova`).
2. Загрузите в него всё содержимое этой папки (`дело гончарова`).
3. Перейдите в **Settings** репозитория → **Pages** → в поле **Branch** выберите `main` (или `master`) и папку `/ (root)` → нажмите **Save**.
4. Через минуту ваш сайт расследования будет доступен по адресу: `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## 📑 Разделы интерактивного расследования

1. **Раздел 01: Главное** — Суть расследования простым языком, хроника событий и ключевые факты без заумных терминов.
2. **Раздел 02: Фонд «Среда»** — Выделение 24,2 млн руб. мэрией через АНО «Мой район», фальшивый ОКВЭД 64.99 («финансовые услуги») и отсутствие лицензий Росприроднадзора.
3. **Раздел 03: Обнальный шлюз «Апра»** — Фирма соратника Гончарова Алексея Крапухина, полиграфические и социологические PR-коды списания денег.
4. **Раздел 04: Слив Госдумы-2021** — Интерактивный электоральный симулятор по Кунцевскому округу № 197. 19 425 голосов, сожженных Гончаровым ради победы пропагандиста ВГТРК Евгения Попова.
5. **Раздел 05: Декабрьская зачистка** — Репрессии внутри «Яблока», разгром молодежной фракции и сторонников Каца после потери партией 250 млн руб. госфинансирования.
6. **Раздел 06: Перехват кассы** — Аппаратный переворот в Московском отделении сразу после ареста Максима Круглова в СИЗО по ст. 207.3 УК РФ.
7. **Раздел 07: Досье фигурантов** — Персональные карточки всех бенефициаров, спойлеров и политзаключенных.
8. **Раздел 08: Репозиторий документов** — 12 аутентичных актов с возможностью просмотра сводок, скачивания в PDF/DOC и изучения первоисточников.
