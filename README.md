# Дело Кирилла Гончарова // Спецпроект издания «Искра»

> **Анатомия системного спойлера: 24,2 млн рублей от мэрии, афера с батарейками, слив выборов в Госдуму и мародерство в «Яблоке»**

Интерактивное антикоррупционное и судебно-форензик расследование деятельности заместителя председателя партии «Яблоко» Кирилла Гончарова.

---

## 🌐 Как открыть и опубликовать

### Локальный просмотр:
Просто откройте файл `index.html` в любом современном веб-браузере (Chrome, Edge, Firefox, Safari).

### Публикация на GitHub Pages:
1. Загрузите файлы этого каталога в репозиторий GitHub.
2. В настройках (**Settings** → **Pages**) выберите ветку `main` и корневую папку `/ (root)`.
3. Сайт расследования будет доступен по адресу: `https://<ваш-логин>.github.io/<репозиторий>/`.

## 📑 Разделы интерактивного расследования

1. **Раздел 01: Главное** — Суть расследования простым языком, хроника событий и ключевые факты без цензуры.
2. **Раздел 02: Кормушка мэрии (24,2 млн ₽)** — Интерактивная листающаяся галерея из 17 улик, аудит проводок АНО «Мой район», 19 блокировок счетов ФНС, видеоархив, ботоферма в YouTube, мем о гончарной мастерской «Среда» (sredastudio.ru), аудит Веб-архива (замороженные новости и тестовая регистрация test@email.com в мае 2023 года) и тайный автопарк Mercedes-Benz.
3. **Раздел 03: Обнальный шлюз «Апра»** — Фирма соратника Гончарова Алексея Крапухина, полиграфические и социологические PR-коды списания денег.
4. **Раздел 04: Спойлер в Госдуму (округ 197)** — Интерактивный электоральный симулятор по Кунцевскому округу № 197. 19 425 голосов, сожженных Гончаровым ради победы пропагандиста Евгения Попова.
5. **Раздел 05: Погром в партии (250 млн ₽)** — Внутрипартийные чистки в «Яблоке», разгром молодежной фракции после потери госфинансирования.
6. **Раздел 06: Аппаратный перехват кассы** — Захват Московского отделения после ареста Максима Круглова по ст. 207.3 УК РФ.
7. **Раздел 07: Досье фигурантов** — Персональные карточки всех бенефициаров, спойлеров и политзаключенных.
8. **Раздел 08: Хранилище улик и документы** — 14 аутентичных актов с возможностью просмотра сводок, скачивания в PDF/TXT и изучения первоисточников.
